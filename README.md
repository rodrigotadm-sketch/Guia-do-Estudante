# Manual do Estudante | Biomedicina UFPR — V1

## Estrutura
- `index.html` — estrutura da página
- `styles.css` — padrão verde responsivo
- `script.js` — renderização, busca e interações
- `dados.json` — conteúdo editável

## Atualização
Para alterar links, textos, FAQ, sistemas, jornada ou acessos rápidos, edite apenas `dados.json`.

## Publicação
Publique os quatro arquivos na mesma pasta (GitHub Pages ou outro servidor estático).
Depois incorpore a URL publicada no WordPress com iframe.

## Observação importante
O post antigo intitulado “MANUAL DO ESTUDANTE 2025” atualmente aponta para um PDF hospedado no site da Biomedicina cujo arquivo/URL é de 2023. Nesta V1, o destaque principal foi direcionado à página da PROGRAP, evitando rotular um PDF antigo como edição 2025/2026.
